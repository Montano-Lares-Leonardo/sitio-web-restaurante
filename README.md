# Sitio Web de Restaurante

Un sitio web de un restaurante de pollo frito ficticio que hice en equipo para practica de HTML, JavaScript, CSS, PHP y MySQL en mi clase de programación en la preparatoria.

En el restaurante hay dos modos, en usuario normal y en usuario de administrador, y se acceden a estos modos iniciando sesión. Los usuarios normales pueden ver el menú, pedir cosas, y enviar quejas sobre el sitio web, y los usuarios administradores pueden añadir, modificar y borrar usuarios y partes del menú, y también todo lo que los usuarios normales pueden hacer.

Para utilizarse este programa, se necesita tener instalado XAMPP y MySQL, y también añadir las bases de datos y tablas dentro del archivo de tipo .sql que esta en este repositorio.
